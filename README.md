# 一键播放 AutoPlay

**看片、听歌、看图，也能逐帧检查专业拍摄素材。**

[下载最新版](../../releases) · [AutoCard](https://github.com/hehedi/AutoCard) · [AutoLibrary](https://github.com/hehedi/AutoLibrary) · [关联软件](#related-apps) · [图文介绍](https://www.bilibili.com/opus/1261109162464509972) · [授权条款](LICENSE)

免费使用 · 支持离线播放 · Windows / Linux · 中文 / English

AutoPlay 是一款兼顾日常影音与专业素材审阅的播放器。除了常见视频、音乐和图片，还支持多种电影摄影机素材与相机 RAW 照片，将 HDR、LUT 预览、逐帧定位、A/B 对比和音画分析放进同一个播放界面。

可独立安装和运行，也可与 AutoCard 导卡流程、AutoLibrary 资产库配合使用。平台与功能支持范围以对应发行包说明为准。
[AutoPlay 主界面](docs/autoplay-main.png)

## 核心功能

| 功能 | 说明 |
| --- | --- |
| **专业素材回放** | 支持 MXF、ProRes、BRAW、R3D、ProRes RAW、ARRIRAW / ARRICORE 等素材及相机 RAW 照片；R3D、BRAW 可直接读取原片，无需先制作整片代理。 |
| **HDR 与 LUT** | HDR 显示、目标亮度适配与 HDR → SDR 映射；加载自定义 LUT 预览 Log 素材与创意色彩效果。 |
| **音乐与音频** | DSD、CUE 分轨、WASAPI 独占与 ASIO 输出；结合封面、歌曲资料、逐字高亮和双语歌词呈现音乐。 |
| **精确审阅** | 正反向逐帧、SMPTE 时间码、精确定位；提供原画、降分辨率与兼容回放档位，以及读取、解码或呈现相关的掉帧提示。 |
| **A/B 画面对比** | 滑动分割、并排视图、帧对齐与差异图；载入参考图片或视频，对照原片、代理及不同处理版本。 |
| **画面与声音分析** | 亮度波形、RGB 直方图、白平衡辅助，以及可缩放、平移和定位的分声道音频波形与频谱。 |
| **截图、录制与标注** | 保存当前帧、对比画面和视频片段；在图片或暂停画面上添加文字、箭头、绘图与马赛克，另存副本。 |
| **桌面与网络扩展** | 默认播放器、Windows 资源管理器缩略图、触屏操作；支持光盘与网络来源、局域网投射及 NDI 发送和接收。 |

## 日常看片与音乐播放

### 让画面适应屏幕

- **HDR 与 SDR 屏幕分别适配**：根据显示环境选择 HDR 显示或 SDR 映射，并调整画面的目标亮度。
- **宽银幕裁切与字幕保护**：按实际画面选择裁切或遮幅，减少上下黑边对宽屏观看的影响；可保留字幕的可见区域。
- **字幕与音轨自由选择**：支持内嵌、外挂字幕及延迟调整，也可加载独立音频文件或其他视频中的音轨。
- **常用操作随手可用**：播放列表、续播位置、章节定位、变速、画面缩放与拖动，以及鼠标、键盘和桌面触屏操作。

### 音乐也有完整的播放界面

- **封面、资料与歌词**：显示专辑封面、歌曲、艺术家及音频规格；支持 LRC / TTML 时间歌词、逐字高亮与双语呈现，界面配色随封面变化。
- **选择自己的音频设备**：在播放器中选择输出设备与输出方式，查看实际采样率、位深和声道信息；支持 DSD 播放与 CUE 分轨。
- **看清声音细节**：按声道查看波形与频谱，缩放、平移并点击定位，也可保存包含歌曲资料和分析图表的截图。
- **连续聆听**：支持循环、随机与连续播放，并为适用的 PCM 播放路线提供曲目无缝衔接。

## 拍摄现场与后期素材审阅

### 从原片开始检查

直接打开支持的摄影机素材和相机 RAW 照片，查看分辨率、帧率、色彩、相机型号及可读取的拍摄参数。照片支持原图查看、旋转与缩放；视频可按播放负载选择原画或较低分辨率。

回放时加载 LUT 查看还原效果，或使用受支持 RAW 格式提供的 SDK 色彩还原。预览中的色彩、缩放和裁切调整不改写源素材。

### 精确定位，再进行比较

使用左右方向键前后逐帧，点击时间输入精确位置，按 SMPTE 时间码检查素材；支持适用帧率下的 DF / NDF 时间码显示与输入。

将截图、图片或视频载入参考视图，以滑动分割、并排或差异图比较画面。双视频可在暂停时分别调整对齐位置，随后按当前时间偏移同步播放；比较时播放 A 素材的音频。

### 用图表辅助判断

亮度波形、RGB 直方图与白平衡辅助可在侧栏查看或叠加到画面上，便于检查曝光和色彩分布；音频波形与频谱用于观察各声道的时间和频率变化。比较完成后，可将当前 A/B 画面保存为截图。

## 更多播放与扩展能力

<details>
<summary>光盘、网络来源与外部设备</summary>

- 打开 CD、DVD、蓝光内容，以及受支持的光盘目录、ISO 与 BIN/CUE 来源；蓝光提供标题与菜单导航。
- 打开 HTTP(S) 链接、M3U / M3U8 播放列表与 HLS 内容；本地播放列表也支持 PLS、CUE。
- 读取摄像头、采集卡等设备提供的输入，选择设备实际支持的视频规格与音频来源。

</details>

<details>
<summary>局域网投射、DLNA 与 NDI</summary>

- 将媒体投射到另一台 AutoPlay、浏览器或兼容的 DLNA 设备。
- 通过 NDI 扩展发送或接收局域网音视频，用于监看与制作流程。
- 接收端支持的格式、定位能力和画质取决于所选传输路线及设备；压缩投射采用兼容画面，不保证保留原始 HDR、位深或 DSD 输出。

</details>

<details>
<summary>画面保存、轻量编辑与插件</summary>

- 截图可保存当前色彩、裁切与旋转效果；视频录制保存当前播放画面及音频，输出重新编码的副本。
- HDR 素材可选择 HDR 截图与录制：截图使用带 PQ / BT.2020 标记的 16 位 PNG，录像使用 10 位 HEVC / PQ；不复制原片的 Dolby Vision 动态元数据。
- 对图片或暂停的视频画面添加文字、箭头、绘图、形状与马赛克，另存图片副本。
- 按需安装 `.autoplayex` 扩展包；在线歌词扩展可搜索、预览、调整并保存歌词。

</details>

<details>
<summary>桌面使用与个性化设置</summary>

- 按视频、音频和图片类别设置默认打开方式；Windows 资源管理器可显示受支持素材的缩略图、音乐封面及分类图标。
- 自定义快捷键、主题、背景和截图位置；提供播放历史、后台常驻与播放器多开设置。
- 桌面触屏支持双指缩放、拖动平移与手势定位；可调整音量，以及系统支持时的屏幕亮度。

</details>

## 与 AutoCard、AutoLibrary 协作

| 软件 | 适合的工作 |
| --- | --- |
| **一键播放 AutoPlay** | 打开媒体、影音播放与专业素材审阅；可独立使用。 |
| **[一键导卡 AutoCard](https://github.com/hehedi/AutoCard)** | 从存储卡导入、校验、备份、转码与归档；素材浏览器共用播放与审阅能力，支持按住空格快速预览。 |
| **[资产库 AutoLibrary](https://github.com/hehedi/AutoLibrary)** | 按专辑、影片、艺术家与目录组织媒体，管理封面和资料，并从本机或远程资料库进入 AutoPlay 播放。 |

AutoLibrary 客户端依赖 AutoPlay；资料库的组织、索引与资料管理由 AutoLibrary 提供。安装 AutoPlay 无需同时安装 AutoCard。

## 下载与安装

1. 在 [Releases](../../releases) 下载对应平台的版本，查看该版本的功能与兼容性说明。
2. Windows 安装包中的 `Setup.exe` 与匹配的 `Setup-1.bin` 数据文件须来自同一发布批次，放在同一目录后运行安装程序。
3. 在组件选择中勾选 AutoPlay，并按使用需求选择专业解码、音频、缩略图、投射及扩展组件。
4. 安装后打开媒体文件，也可在设置中选择音频设备、默认打开方式与个人偏好。

**软件和功能组件均免费。** 部分专业解码、NDI、图片编辑及在线扩展通过可选组件提供，可按需安装，减少不需要的组件占用；个别兼容功能需另行安装厂商组件，具体见下方说明。

## 格式与设备支持说明

<details>
<summary>展开查看专业格式、HDR 与音频输出范围</summary>

| 项目 | 支持说明 |
| --- | --- |
| **BRAW / R3D** | 使用对应 SDK 读取原素材，提供回放、元数据、截图与缩略图等能力；可用的 GPU 路线和播放性能取决于素材、设备与驱动。 |
| **ARRIRAW / ARRICORE** | 由 ARRI 解码组件提供回放、元数据和 LogC3 / LogC4 至 Rec.709 还原；HDE 压缩素材另需兼容的 CODEX HDE 组件，可用范围以发行说明为准。 |
| **ProRes RAW** | 使用 Vulkan 解码，需兼容的 GPU |
| **HDR / Dolby Vision** | HDR10、HDR10+、HLG 及 Dolby Vision(还可区分 Profile 和增强层) |
| **DSD** | 支持 DSF / DFF 等来源；兼容 ASIO 驱动可原生输出 DSF 与未压缩 DFF，其他适用路线使用 PCM 播放。当前不提供 DoP 或 SACD ISO 解析。 |
| **多声道与原码输出** | 支持相应 PCM 声道布局及部分 Dolby / DTS 编码的原码输出。当前原码路线仅适用于受支持结构、从起点以原速播放，定位、软件音量与混音等操作受限，不等同完整 Atmos / DTS:X 对象解码。 |
| **光盘与投射** | 光盘导航、菜单及投射能力取决于可读取的来源、已安装组件与接收端；不同协议的画质和功能范围不同。 |

Windows 的 HDR 显示、WASAPI / ASIO、资源管理器缩略图等功能依赖相应平台与组件，其他平台请以对应发布包说明为准。

高分辨率、高帧率和 RAW 回放性能受 CPU、GPU、驱动、存储速度及图表处理负载影响。原画与降低分辨率档位提供不同的回放选择，不承诺任意设备均可满帧播放。

图表、差异图和显示调整用于辅助审阅，不能单独证明显示器已完成物理校准。各格式可用的高级处理功能以当前回放路线为准。

</details>

## 项目缘起

AutoPlay 最初只是 AutoCard 素材浏览器里的一个快速预览窗口，后来随着拍摄工作与日常影音需求逐步发展为独立播放器。它的出发点一直很直接：让拍摄时常用的审阅工具，也能在日常看片、听歌和看图时顺手使用。
